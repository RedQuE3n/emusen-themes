# emusen-themes

Themes for [EmuSen](https://github.com/RedQuE3n/EmuSen)'s big picture mode, every theme credited to its authors and kept
under its own licence.

Big picture reads ES-DE's theme format, so the themes here are ES-DE themes: ones made for EmuSen and ones imported from
their authors. EmuSen downloads them from this collection's releases; none is bundled with the program.

## Layout

- `themes/<theme>/`: a theme made for EmuSen, with its own `LICENSE`.
- `upstream/<theme>/`: a theme exactly as imported from its authors, with its licence beside it (see `ATTRIBUTION.md`),
  so it can be refreshed from its origin and compared.
- `ATTRIBUTION.md` lists every theme, its authors, its licence, where and when it came from.
